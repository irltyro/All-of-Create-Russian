# -All-of-Create
Руссификатор Квестов для Сборки: All of Create,  сделанный при помощи ИИ, на версию v2.5 neoforge


ИНСТРУКЦИЯ: 

1.Скачайте Zip архив нажав на зеленую кнопку "<code>"   (НЕ В РЕЛИЗАХ)

2.Распакуйте архив (README.md можно удалить)

3.Зайдите в папку сборки (instance) <..\instances\All of Create Aeronautics..>

4.Зайдите в папку < ..\minecraft\config\ftbquests\quests\lang > и вставьте туда файл из архива

5.Чтобы перевод применился в настройках Майнкрафта поставьте русский язык!

*ВАЖНО* другие файлы в выше указанном папке не трогать
